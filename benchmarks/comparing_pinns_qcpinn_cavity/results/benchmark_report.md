# Benchmark Report: QCPINN vs PINN vs CFD

## 2D Lid-Driven Cavity Flow (Re=10)

- **Geometry**: unit square [0.0, 1.0] x [0.0, 1.0]
- **PDE**: 2D steady incompressible Navier-Stokes; Re = 10.0 (mu=0.1, rho=1, U=1.0, L=1)
- **Boundary conditions**:
  - Left, bottom, and right walls: no-slip (u=v=0)
  - Top lid: u=1.0, v=0
  - Pressure reference: p=0 at the lower-left corner
- **Sampling**: uniform -- 201 boundary points, 2500 interior points
- **Resampling**: disabled (the collocation set is fixed)
- **Training**: L-BFGS(100 epochs, threshold=None); no Adam warm-up
- **Loss**: `df.calc_loss_simple` (unweighted BC + PDE sum)
- **Seeds**: [69]
- **Formulation note**: this is a DeepFlow-compatible direct `(u, v, p)` adaptation. The referenced paper learns `(psi, p)` and derives velocity from the stream function.
- **Runs per model**: PINN = 1, QCPINN = 1 (median-loss run used for representative fields)
