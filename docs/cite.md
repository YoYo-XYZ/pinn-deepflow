# Citing DeepFlow

If DeepFlow contributes to a project that leads to a scientific publication,
please cite it. The project does not yet have a paper or DOI; use the
repository citation below.

## Repository citation

> Thammatorn Jamraschai. *DeepFlow: Physics-Informed Neural Networks for
> Fluid Dynamics* (v0.1.3). GitHub repository, 2026.
> https://github.com/YoYo-XYZ/pinn-deepflow

## BibTeX

```bibtex
@misc{deepflow,
  author       = {Jamraschai, Thammatorn},
  title        = {{DeepFlow}: {Physics-Informed} {Neural} {Networks} for {Fluid} {Dynamics}},
```

## Background reading

The methods DeepFlow builds on are described in the following papers:

- Physics-informed neural networks (Raissi, Perdikaris, Karniadakis 2019):
  [arXiv:1711.10561](https://arxiv.org/abs/1711.10561)
- RAR-G adaptive sampling:
  [arXiv:2207.10289](https://arxiv.org/abs/2207.10289)
- R3 residual-based adaptive refinement:
  [arXiv:2207.02338](https://arxiv.org/abs/2207.02338)
